🔌 Services

📊 DashboardService

  • navItems → Sidebar navigation
  • statCards → Top 6 stat tiles
  • genStats → Generator details
  • genGroups/Zones → Dropdown options
  • tankMetrics → Fuel tank data
  • fuelFlow → Fuel flow data
  • perfLoad/Fuel → Donut charts
  • runningMetrics → Right column
  • alerts → Alert items
  • alertBadges → Badge counts

🎨 ThemeService

  • sidebarCollapsed → Boolean signal
  • toggle() → Toggle sidebar
  • collapse() → Force close
  • expand() → Force open

🔔 AlertsService

  • visible() → Filtered alerts
  • viewMoreLabel() → Toggle text
  • expanded → State toggle

⚡ Key Patterns

🏗️ Architecture

  • Standalone Components - No NgModules
  • Signals-based State - signal(), computed()
  • OnPush Change Detection - Every component
  • ViewEncapsulation.None - Global styles

🚀 Performance

  • Lazy Loading - All feature routes
  • Mock-First - Ready for API swap
  • Content Projection - ng-content
  • Stub Infrastructure - Guards, Interceptors
